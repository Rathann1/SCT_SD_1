# 🌡️ Temperature Converter

A simple GUI-based temperature converter developed using **HTML, CSS, and JavaScript**.

### Features
- Converts between Celsius, Fahrenheit, and Kelvin
- Simple and user-friendly interface
- Handles decimal values and invalid inputs

### How to Run
1. Download or clone the repository.
2. Open `index.html` in any web browser.
3. Enter the temperature, select the units, and click **Convert**.

### Technologies Used
- HTML5
- CSS3
- JavaScript
